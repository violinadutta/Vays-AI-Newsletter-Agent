# ── LLM transport ────────────────────────────────────────────────────────────
# The OpenAI *protocol* is spoken over plain httpx (see
# modules/ai/openai_compatible.py). The `openai` SDK was evaluated and DROPPED:
# its value is streaming, its own retry layer and typed errors — we need none of
# those (tenacity + a circuit breaker cover it) and it obscured the error mapping
# that turns a 401 into "the API key doesn't match the notebook". One fewer
# dependency on the code path that matters most at handover.
# No OpenAI model is ever called; the protocol is just the lingua franca that
# vLLM, TGI, Ollama and every commercial endpoint share (D-2, D-17).
tenacity>=8.2,<10.0             # Apache-2.0  (retry/backoff)
